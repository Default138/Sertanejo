# Sertanejo

Site de várias páginas sobre uma dupla sertaneja (Luan & Mateus), feito para praticar **HTML** e **CSS** com layout e estilo escritos à mão.

## Páginas

| Arquivo | Conteúdo |
|---|---|
| `index.html` | Página inicial: sobre a dupla, álbum mais recente e próximo show |
| `historia.html` | Biografia: a história da dupla |
| `discografia.html` | Álbuns e músicas |
| `fotos.html` | Galeria de fotos (as imagens ficam em `FotosSert/`) |
| `agenda.html` | Agenda de shows |
| `contatos.html` | Contatos |
| `checkout.html` | Página de pagamento (brincadeira "E o PIX?") |

O estilo de todas as páginas está em `style.css`.

## Como ver

Não precisa instalar nada: abra o `index.html` no navegador.
Os ícones vêm do Bootstrap Icons, carregado pela internet, então é preciso estar conectado para vê-los.

## Tecnologias

HTML5, CSS3, Bootstrap Icons
